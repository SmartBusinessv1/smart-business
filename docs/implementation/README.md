## Forward Naming Guidance (new records only)

For implementation records created from 2026-10-04 onward:

1. **Use the current mission ID form**, `SB-P-1.x` (with the hyphen), for example `SB-P-1.13`.
2. **Use a mission-scoped folder** (`docs/implementation/SB-P-1.x/`) when a mission produces more than one durable implementation artifact. Put evidence under `SB-P-1.x/evidence/`.
3. **A single flat file** is acceptable only for a one-off or cross-mission record, named with its mission ID prefix.
4. **Never rename or move historical records** to fit this guidance.
5. **Add a row to this index** when a new mission folder or flat record is added.

This guidance is operational navigation, not governance authority. Product Mission records also follow Source 18 (`merge/active/18_SB-P_Mission_Lifecycle_and_Delivery_Framework.md`).
