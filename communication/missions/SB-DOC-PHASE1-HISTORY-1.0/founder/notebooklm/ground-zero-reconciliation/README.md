Do not demote a Founder-created capability merely because an older assistant called it MVP, future, later, post-pilot, optional, difficult or an add-on.

The required reconciliation model is:

**preserve original problem + preserve original feature intent + preserve later Founder correction + build the current secure human-centered version.**

## Current Founder corrections already protected

The final reconciliation must carry these current decisions forward:

- Daily Intelligence uses **7:00 AM / 10:30 AM / 10:00 PM**; older timing is historical only.
- Basic Voice is included in Ledger and Manager; Voice Plus is deeper premium voice conversation.
- Smart Stock Assistant is a Ledger add-on path; Manager already includes Stock Intelligence.
- Standard POS bridge is allowed. Custom client-specific POS modification inside core is rejected; use integration/extension layers.
- Staff access is permission-scoped; employees do not receive owner financial intelligence by default.
- Counter/Risk Intelligence observes and reports; it does not accuse employees or autonomously judge guilt.
- Reorder Intelligence asks for confirmation by default; automatic execution requires explicit stored owner-delegated authority.
- Ask CFO is an intelligence/clarity feature, not autonomous business authority.
- Attendance uses purpose-limited, point-in-time location verification rather than continuous tracking.
- Attendance/payroll corrections preserve raw events and approved human context.
- Smart Order & Delivery is an approved add-on for **Ledger and Manager**, intended before the first 10 pilot merchants; it is not a marketplace.
- Customer silence after otherwise well-proven delivery is not automatically a delivery exception.
- Smart Credit Awareness warns and provides context; it does not block owner decisions.
- Payment/bank matching must not guess when multiple plausible matches exist.
- Financial reconciliation stops only the uncertain write/link and keeps unrelated operations available.
- Support Automation preserves the **100+ FAQ** direction, FAQ-first handling, English/Malayalam/Manglish, AI escalation only when needed, ticketing and privacy-respecting review.
