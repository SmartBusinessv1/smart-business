## 4. Major Institutional Lessons Surfaced

The retrospective records, among others:

- Founder philosophy remained stable while product definition became more precise;
- preserve the merchant problem and approved capability while evolving unsafe/obsolete mechanisms;
- short summaries can dangerously compress Founder intent;
- preserve Founder rationale, not only final decisions;
- distinguish direct Founder wording, evidence-based paraphrase, later canonical Product Truth and assistant-created synthesis;
- capability/access/readiness/authority are different states;
- repository truth and runtime truth are different evidence layers;
- local mission scope must coexist with global product-completion responsibility;
- Founder attention should be protected through repository-first AI handover rather than manual message relaying;
- ask the Founder only when existing evidence cannot resolve a genuine product/governance/commercial/privacy decision;
- maximum clarity, minimum necessary ceremony;
- institutional memory transfers judgement, not stale current authority;
- Mission Control succession must hydrate governance, institutional memory, historical communication, current state and judgement before live execution resumes.
