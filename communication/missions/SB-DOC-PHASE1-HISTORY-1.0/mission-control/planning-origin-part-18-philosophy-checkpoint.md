# Founder-derived principles to preserve

1. Basic voice access belongs in both subscriptions; premium value should come from deeper conversational intelligence rather than charging for language access.
2. Voice output should respect merchant attention; longer is not automatically better.
3. Smart Business should remain usable even when the primary communication channel is unavailable.
4. Product Truth must explain every feature deeply enough that implementation does not invent user behaviour.
5. User permissions and authority limits belong to Product Truth.
6. Expected user experience is a first-class part of feature definition.
7. Shared architecture should be reused across later features rather than duplicated.
8. Fair usage should preserve genuine customer freedom while protecting service quality and sustainability.
