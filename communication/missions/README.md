## How to Read the Status Columns

- **Recorded status** is quoted from the mission's own `README.md`. Mission READMEs are not always updated after closure, so a recorded status may be historical.
- **Other repository evidence** lists independent records (archive packages, `mission-control/mission_memory.md`) where they exist.
- Where neither establishes a current status, the entry says "see mission records". This index does not infer status.
