## 1. Purpose and independence

Source 18 §3.2 item 6 requires an inventory of pointers into the source text, kept apart from the FCTM, so that an omitted obligation shows up as a pointer with no matching row. This inventory restates no requirement.

To avoid that, Section 2 below is produced mechanically from the contract files: a parser splits each file at its `## N.` headings and counts dash items, numbered items and `###` subsections. It never reads the FCTM. The FCTM row count appears only in Section 3, as the comparison column.
