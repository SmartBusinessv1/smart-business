## 4. Set-based completeness check (against the FCTM)

### 4.1 Method

A parser (`parse.py`) reads each source blob and enumerates, for every `## N.` section, each bullet (`b<k>`), numbered item (`n<k>`) and prose paragraph (`p<k>`) in source order. This enumeration comes from the source text, not from the FCTM. The FCTM generator (`build.py`) then records, for every row, the source locators it cites. The checks compare the two sets. The scripts were run from the Claude Code session scratchpad with `python -I`, against copies of the contract blobs exported with `git show main@eacc4610:<path>`; they are not committed.
