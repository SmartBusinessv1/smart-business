# Source Authority

This document defines how Smart Business proves that a feature is truly
complete.

A feature is NOT complete because:

-   code exists
-   UI exists
-   database exists
-   AI replied once

A feature is complete only when:

Product Truth fulfilled + Implementation completed + Security verified +
User experience confirmed + Real business behaviour tested

# Conversation Acceptance

Verify:

- Conversation works consistently through WhatsApp and Conversation Workspace
- Same Business Memory is used
- Same AI understanding is used
- Same permissions apply
- Same conversation history is available where appropriate

Reject duplicate conversation behaviour between channels.

# Channel Independence Acceptance

Verify:

- Business workflows continue if one approved communication channel is unavailable
- Business logic is identical across approved channels
- No channel-specific business rules exist.

------------------------------------------------------------------------

# Dual Authentication Acceptance

Verify:

- WhatsApp login
- Email/password login
- Future authentication methods map to the same Smart Business identity
- Permissions remain identical regardless of authentication method

------------------------------------------------------------------------

# Platform Stewardship Acceptance

Verify:

- Platform insights support continuous improvement

- Core services are reused instead of duplicated
