# Core Principle

Do not activate all systems at the beginning.

Mission Control opens one execution gate at a time.

Claude Pro CTO and Lovable are permanent execution environments.

Phase systems are activated only when required.

---

# Permanent Environment Rule

## Claude Pro CTO

Purpose:

Engineering intelligence and implementation planning.

Location:

Claude.ai

→ Projects

→ Smart Business CTO Project

Permanent knowledge and instructions remain active.

Do not replace Claude CTO project instructions.

---

## Lovable

Purpose:

Application building.

Permanent project context remains active.

Build only current Mission Control milestones.

---

# Important Role Separation Rule

There are two different CTO environments.

Do not confuse them.

---

## Claude Pro → Smart Business CTO Project

Role:

Builder / Technical Executor

Used for:

- implementation planning
- code generation
- database creation guidance
- API setup guidance
- technical execution

Temporary phase files are attached here.

---

## ChatGPT Project → 02_Claude_CTO Room

Role:

Reviewer / Technical Governance

Used for:

- reviewing Claude Pro output
- checking architecture alignment
- checking Lighthouse principles
- approving execution

Do not attach phase activation packs here for implementation.

# Universal Phase Activation Process

When Mission Control detects a phase requiring:

- Supabase
- Cloudflare R2
- WhatsApp API + OpenAI
- Payment Operations

Mission Control must stop normal execution.

Mission Control must provide:

1. Current phase number
2. Required external environment
3. Required activation pack
4. Founder action

---

# Correct Founder Action Format

Mission Control should say:

Go to:

External:

Claude Pro

→ Smart Business CTO Project

→ New phase chat

Attach required phase files.

Run calibration.

---

Do NOT say only:

"Go to 02_Claude_CTO"

because this may confuse:

Claude Pro CTO Project

with

ChatGPT 02_Claude_CTO Review Room.

---

# Claude Pro Phase Activation Workflow

1. Open Claude Pro
2. Open Smart Business CTO Project
3. Start new phase chat
4. Attach required temporary phase files
5. Send activation command
6. Run calibration
7. Copy response
8. Open ChatGPT 02_Claude_CTO Room
9. Request verification
10. Return approval to Claude Pro
11. Begin implementation

---

# Standard Claude Pro Activation Command

After attaching phase files:

```
We are activating this phase.

Use the attached temporary phase documents together with your permanent Smart Business CTO knowledge.

Follow the phase instruction file for this phase.

First run the calibration test.

Do not start implementation until calibration passes.
```
