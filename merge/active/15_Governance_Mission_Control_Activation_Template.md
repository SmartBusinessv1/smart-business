# Standard Activation

## 1. Mission Information

- Mission ID
- Phase
- Milestone
- Specialist Room
- Date
- Estimated Duration
- Status

## 2. Mission Objective

One measurable mission only.

## 3. Mission Inputs

- Approved source files
- Previous mission outputs
- Founder approvals
- Dependencies satisfied
- Required evidence received

## 4. Source Synchronization Check

Before authorizing any mission verify the latest approved:

- Roadmap
- Environment Activation
- Product Truth
- Product Execution and Release Framework

If a governing source changed, complete inheritance review first.

## 5. Room Authority

Authorized only for this mission.

Shall not:

- redesign approved source files
- modify roadmap
- modify Product Truth
- bypass Mission Control
- activate another room
- execute future phases
- reopen Founder-approved decisions
- introduce uncontrolled feature expansion

## 6. Inheritance Verification

Mission Control workflow:

Read
↓
Compare
↓
Inherit
↓
Review
↓
Freeze
↓
Replace

No mission executes from obsolete governance.

## 7. Expected Deliverables

- Mission outputs
- Configurations
- Documents
- Validation results

## 8. Mission Outputs

- Deliverables
- Evidence
- Observations
- Recommendations
- Handover package

## 9. Completion Criteria

List measurable success conditions.

## 10. Required Evidence

- Screenshots
- URLs
- Logs
- Tests
- Confirmations

## 11. Quality Gate Checklist

- Scope respected
- Approved sources followed
- Deliverables complete
- Evidence attached
- No unauthorized work
- Founder approval identified where required
- Ready for Mission Control review

## 12. Risk Register

Risk | Impact | Mitigation | Escalation

## 13. Observations

Out-of-scope discoveries only.

## 14. Knowledge Worth Preserving

Record only enduring knowledge:

- governance improvements
- architectural patterns
- implementation practices
- scalability lessons
- operational insights

Do not record routine task completion.

## 15. Lessons Learned

Classify as:

- Project-specific
- Smart Business Governance Candidate
- Lighthouse Architect Candidate
- Organization-wide Capability

Mission Control recommends.

Founder decides.

## 16. Conversation Continuity Status

Record:

- current phase
- active mission
- completed milestones
- approved source versions
- pending Founder decisions
- immediate next action

## 17. Handover Package

- Completed work
- Evidence
- Observations
- Lessons learned
- Recommendations

## 18. Failure Protocol

Return:

- Completed work
- Blocking issue
- Evidence
- Recommendations

## 19. Next Authorized Room

Recommendation only.

Mission Control authorizes activation.

- Not Started
- In Progress

- Ready for Review
- Complete

- One measurable mission per activation.
- Mission IDs mandatory.
- Human-in-the-loop governance mandatory.
- No modification of approved governance without Founder approval.
- Governance evolves through controlled inheritance.
- Protect Truth.
- Protect Momentum.
- Protect Continuity.
