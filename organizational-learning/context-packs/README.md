# Context Packs

Deterministic mission-start context-pack proof output, generated by
`organizational-learning/scripts/context-pack.mjs` from the existing,
unmodified `PromotionReviewSchema` records under
`organizational-learning/promotions/`.

Path convention: `<related mission id>/<profile description>.json`.

Every pack in this directory is an **output**, not authority. A pack:

- performs no AI/model ranking -- every inclusion/exclusion decision is a
  plain, explainable structural check (maturity, scope match, revision
  binding, provenance, supersession, contradiction state), never a
  judgment about which lesson matters more;
- is not governance, not Product Truth, and not itself evidence for its
  own claims -- the underlying evidence remains the pinned mission
  records each item's `provenance` field points at;
- creates no `INSTITUTIONALISED` or `ORGANIZATION_WIDE` state merely by
  existing, and never activates a real Product Mission by referencing a
  synthetic or real mission ID in its profile;
- always states, verbatim, `"context, not authority"`.

A pack built from a synthetic profile (as this directory's current
contents are) proves the deterministic retrieval/construction path only.
It does not represent a real mission-start query and grants no mission
activation authority.
