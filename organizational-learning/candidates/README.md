# Candidates

Candidate learning items generated by an authorized Stage 2B AI synthesis
session, validated against
`organizational-learning/schemas/candidate-learning-item.schema.ts`.

Path convention: `<mission_id>/<candidate id>.json`.

Every file in this tree is, and must remain, `maturity: CANDIDATE` and
`authority_effect: NONE`. This is not a promoted or institutional
registry: nothing here has been reviewed, corroborated, validated, or
institutionalised. Promotion is a separate, human-controlled write path
(`organizational-learning/schemas/promotion-review.schema.ts`) that does
not yet have an implemented execution path or a dedicated storage
location — creating one is outside Stage 2B's authorized scope.

A candidate's presence here means only that an AI synthesis session
drafted it from already-screened, committed evidence for a specific
closed mission. It carries no organizational authority and must not be
read as approved guidance until a human reviewer promotes it through
the separate promotion contract.
